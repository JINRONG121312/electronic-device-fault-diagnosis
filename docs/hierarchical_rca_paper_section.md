# 面向未见服务-故障组合的分层联合根因诊断

## 1. 现有方法的可检验缺陷

现有多源融合方法分别得到服务后验和故障类型后验，再用简单加和生成
`service:fault_type` 根因排序。该做法隐含了一个未经验证的假设：服务边缘最优和故障类型边缘最优的组合，就是联合根因最优。
在 RE2 测试集上，`temporal_signal_fusion` 的服务 Top-1 为 0.6852，但根因 Top-1 和 Top-3 都为 0.2407，说明服务定位信息没有转化为有效的组合排序；Top-3 与 Top-1 没有增益也说明候选排序退化。

本文将问题定义为：

> 在训练集中未出现目标服务-故障组合时，如何利用多模态时序证据保持服务与故障类型的联合一致性，并提高根因候选排序质量？

RE2 的 18 个测试根因组合全部未在训练集中出现，因此该划分直接检验组合泛化，而不是标签记忆。

## 2. 分层联合时序融合

方法先分别计算服务分布和故障类型分布，再对候选笛卡尔积进行联合重排：

\[
S(s,f|x)=w_s P(s|x)+w_f P(f|x)+w_t T(s,f|x)+w_c C(s,f).
\]

- `P(s|x)`：由指标突变、日志组件和调用链得到的服务分布。
- `P(f|x)`：原始时序信号与时序 TF-IDF 故障分类器的开发集加权分布。
- `T(s,f|x)`：同一指标突变同时支持服务 `s` 和故障类型 `f` 的归一化证据强度。
- `C(s,f)`：训练集服务-故障共现先验，采用拉普拉斯平滑，未见组合不会被赋为零概率。

权重只在 dev 集选择，test 集不参与调参。RE2 选择结果为：

`model_fault_mix=1.0`，`temporal_pair_weight=0.5`，`compatibility_weight=0.0`。

因此当前主结果的实际增益来自“时序故障后验 + 服务-故障时序一致性重排”；兼容性先验作为可复现实验项保留，但没有被强行纳入最终模型。

## 3. 针对缺陷的评价指标

主指标保留根因 Top-1、Top-3、Top-5、MRR 和 Macro-F1，并新增：

| 指标 | 目的 |
|---|---|
| `root_top3_gain = Top-3 - Top-1` | 检验候选排序是否提供有效备选，而不是重复输出同一候选 |
| `unseen_root_top-k`、`unseen_root_mrr` | 只在训练未出现的服务-故障组合上衡量组合泛化 |
| `factor_service_correct_rate` | 服务边缘定位能力 |
| `factor_fault_correct_rate` | 故障类型边缘识别能力 |
| `factor_both_correct_rate` | 两个独立因子同时正确的上限诊断 |
| `combination_consistency_rate` | 联合根因是否等于两个边缘预测的简单组合 |
| `service_only_correct_rate`、`fault_only_correct_rate` | 定位“服务正确但故障错”或反之的误差来源 |

## 4. RE2 主实验对比

所有方法使用相同的 train/dev/test 划分和相同的证据字段，测试集 54 个样本、18 个未见根因组合。

| 方法 | Root Top-1 | Root Top-3 | Root Top-5 | Root MRR | Root Macro-F1 | Service Top-1 | Fault Macro-F1 |
|---|---:|---:|---:|---:|---:|---:|---:|
| BARO（适配复现） | 0.2963 | 0.3519 | 0.3889 | 0.3723 | 0.2828 | 0.8333 | 0.2380 |
| Multi-source BARO（适配复现） | 0.3148 | 0.5370 | 0.5741 | 0.4390 | 0.3278 | **0.8519** | 0.2687 |
| CloudRanger（适配复现） | 0.2407 | 0.2407 | 0.2407 | 0.2431 | 0.2448 | 0.8333 | 0.1845 |
| TraceRCA（聚合 span 适配复现） | 0.0370 | 0.0370 | 0.0370 | 0.0370 | 0.0444 | 0.0370 | 0.0606 |
| `hierarchical_temporal_fusion` | **0.3333** | **0.5926** | **0.6852** | **0.4664** | **0.3778** | **0.6852** | **0.3535** |

相对最强文献基线 Multi-source BARO，Root Top-1 提升 1.85 个百分点，Root Top-3 提升 5.56 个百分点，Root Top-5 提升 11.11 个百分点，Root MRR 提升 2.74 个百分点，Fault Macro-F1 提升 8.48 个百分点。需要同时报告 Multi-source BARO 的服务 Top-1 更高（0.8519 对 0.6852），说明本文方法的收益来自故障类型与联合根因重排，而不是单纯提高服务定位。由于测试组合全部未见训练集，以上结果应表述为“未见服务-故障组合上的组合排序泛化提升”；在完成配对显著性检验前，不使用“显著优于”的措辞。

## 5. 论文中应如何下结论

可以声称：分层联合时序融合缓解了服务定位与故障类型识别之间的组合排序断裂，并在未见组合设置下提升根因候选排序质量。

不能声称：该实验已经验证硬件边界定位、FRU 更换决策、接口路径故障或维修闭环能力。数据集是微服务软件故障注入数据，结论范围应限定为面向微服务信息系统的多源可观测数据融合根因诊断。

下一节实验应报告四组消融：去掉 `T(s,f|x)`、去掉模态质量权重、仅使用边缘组合、完整方法，并沿用上述未见组合指标。
