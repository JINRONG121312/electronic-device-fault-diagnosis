# 故障诊断研究定位

## 论文主线

本项目建议把研究落点放在“面向计算机设备的软件层故障诊断”，而不是“可更换模块诊断”。可更换模块仍然保留，但它只作为诊断结果面向维修决策时的服务性标签，用来判断故障是否需要硬件更换、是否应优先软件修复、是否需要进一步主动测试。

推荐主线表述：

> 面向计算机设备的软件栈故障诊断与主动证据采集方法研究。

该主线区别于旋转机械设备故障诊断。旋转机械诊断通常依赖振动、声学、电流等连续物理信号，目标是识别轴承、齿轮、转子等机械部件故障。计算机设备的软件层故障诊断则面对日志、崩溃转储、系统事件、驱动状态、配置、固件、资源指标和主动测试结果，核心问题是从异构证据中区分软件、驱动、系统、固件、配置、外部环境和硬件边界故障。

## 推荐论文标题

优先推荐：

1. 面向计算机设备的软件层故障诊断与主动证据采集方法研究
2. 面向计算机设备的异构证据融合故障诊断方法研究
3. 面向计算机设备系统异常的软件栈故障诊断方法研究

如果希望突出维修决策但不让 FRU 成为主线：

1. 面向计算机设备的可解释故障诊断与维修决策方法研究
2. 面向电子设备软件硬件边界的故障诊断与修复决策方法研究

不建议使用以下标题作为主标题：

1. 面向计算机设备的可更换模块故障诊断方法研究
2. 面向笔记本电脑 FRU 的故障定位方法研究

这些标题容易把论文带向售后维修和硬件换件，不符合偏软件层面故障诊断的主线。

## 诊断对象

一级诊断对象应是故障来源，而不是可更换模块：

- driver_fault：驱动异常、驱动冲突、第三方驱动导致崩溃
- os_fault：操作系统组件、服务、更新、系统文件异常
- firmware_fault：BIOS、EC、ACPI、UCSI、固件配置异常
- configuration_fault：电源策略、禁用设备、网络配置、启动配置异常
- external_environment_fault：电源适配器、路由器、外接设备、线缆、使用环境异常
- hardware_fault：内存、SSD、电池、显示、无线网卡、主板等硬件故障
- mixed_or_uncertain：证据不足或多源故障

二级诊断对象才是服务性对象：

- software_repairable：更新、回滚、重装、修复系统组件
- firmware_repairable：升级 BIOS/EC、恢复设置、调整固件策略
- configuration_repairable：修改配置、恢复服务、清理资源
- externally_reproducible：更换外部环境或外设复测
- replaceable_hardware：需要更换 FRU 或服务组件
- need_more_evidence：需要主动补采证据

蓝屏、黑屏、充电失败、无法联网、启动失败等属于 symptom 输入，不是独立诊断分支。程序功能上应先完成故障分类，再由决策层给出处理措施。

## 可更换模块的定位

FRU/可更换模块与故障诊断有关系，但不是核心研究对象。它在本项目中的研究价值是：

1. 把“异常检测”推进到“维修可执行诊断”。
2. 支持区分硬件故障和软件/配置/环境故障。
3. 用“不必要换件率”评价诊断系统是否减少错误维修。
4. 在硬件确有嫌疑时，把根因映射到可维修对象。

因此论文中建议使用“服务性标签”或“维修决策标签”，少用“FRU 诊断”作为主线措辞。

## 方法框架

建议把项目方法写成六层：

1. 证据层：统一 Evidence Schema，采集日志、指标、配置、崩溃转储、主动测试和维修结果标签。
2. 知识层：构建设备故障本体，建模软件、驱动、系统、固件、配置、外部环境、硬件和服务性对象。
3. 候选生成层：根据症状和证据生成候选根因，包括软件类、固件类、环境类和硬件类候选。
4. 证据融合层：用规则加权、Dempster-Shafer 或贝叶斯方法输出 belief、uncertainty、支持证据和冲突证据。
5. 主动诊断层：根据候选不确定性、测试收益、成本和风险推荐下一步最有价值证据。
6. 决策层：在故障分类完成后，输出软件修复、配置修复、固件升级、环境复测、硬件确认测试、硬件更换或继续补采证据。

## 实验评价

评价指标应围绕故障诊断，而不是只围绕换件：

- Root cause top-1 accuracy
- Root cause top-3 accuracy
- Software/firmware/hardware fault-origin accuracy
- FRU / Non-FRU boundary accuracy
- Mean reciprocal rank
- Evidence sufficiency prediction accuracy
- Next-best-test effectiveness
- Unnecessary replacement rate
- Average evidence collection steps

其中“不必要换件率”是辅助指标，用来体现维修决策价值，不应成为唯一核心指标。
