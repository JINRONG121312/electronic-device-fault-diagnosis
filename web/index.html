系统使用说明

本系统用于电子设备故障诊断研究，面向自机检测、互机诊断、证据采集和诊断决策实验。

1. 打开工作台浏览器入口是 http://localhost:8780/；/api/health 只用于服务健康检查。
2. 自机检测当前机器能运行程序时，扫描本机、采集 runtime_info，并执行完整诊断流程。
3. 互机诊断诊断主机通过 Target Agent、离线证据包或现场描述诊断另一台故障机器。
4. 研究管理保存证据、维修动作和维修结果标签，用于后续实验评估。

启动和访问

启动 Web 服务后，只需要打开根路径页面；健康检查接口不是前端页面。

启动服务 
powershell -ExecutionPolicy Bypass -File scripts\start_web_server.ps1
浏览器访问 
http://localhost:8780/
  • 如果页面只显示 JSON，通常是打开了 http://localhost:8780/api/health，请改为打开根路径。
  • 服务启动后会输出 DashboardUrl 或 OpenThisInBrowser，优先使用该地址。

诊断流程

蓝屏、黑屏、无法充电、无法联网等都作为故障症状输入，不单独作为诊断模块。

证据采集
  -> 异常检测 anomaly_detection
  -> 故障分类 fault_classification
  -> 软硬件边界判断 boundary_assessment
  -> 故障决策 fault_decision
  -> 维护策略和补采建议
异常检测判断当前设备状态是否偏离正常运行状态，输出健康度和异常项。
故障分类输出驱动、系统、固件、配置、环境、硬件或混合不确定等故障来源。
边界判断判断故障更偏软件侧、硬件侧、软硬件边界还是证据不足。
故障决策在分类之后给出软件修复、继续补采、边界区分测试或硬件服务建议。

自机检测怎么用

适用于本机操作系统还能运行程序的场景。

推荐步骤

  1. 进入“自机检测”页面。
  2. 点击“扫描本机”，生成或更新设备画像。
  3. 点击“采集数据”，更新 runtime_info.json。
  4. 点击“开始诊断”，查看健康度、异常检测、故障分类、边界判断和决策结果。
  5. 如提示证据不足，按“下一步排查”补充主动测试或故障时间窗口日志。

结果解读

  • 健康度用于判断当前异常是否影响运行，不等于最终根因。
  • 故障分类是研究主标签，例如 driver_fault、os_fault、hardware_fault。
  • 软硬件边界用于决定是否需要先做区分测试，避免过早建议换硬件。
  • FRU 或可更换模块属于维修服务标签，不是故障分类标签。

互机接口采集怎么工作

装载本程序的机器是 Controller，被诊断机器运行轻量 Target Agent。

Controller本 Web 系统，负责连接目标机、下发采集任务、接收证据包、运行诊断。
HTTP APIController 访问 Target Agent 的 /api/health、/api/capabilities、/api/collect。
Target Agent运行在被诊断机器，读取本机日志、指标、设备状态和崩溃转储元数据。
Evidence PackageTarget Agent 返回标准证据包，Controller 自动转为 runtime_info 并执行诊断。
诊断主机 Controller
  -> POST /api/target/probe
  -> Target Agent: GET /api/health + /api/capabilities
  -> POST /api/target/collect
  -> Target Agent: POST /api/collect
  -> Evidence Package
  -> 异常检测 -> 故障分类 -> 软硬件边界判断 -> 故障决策

互机诊断三种场景

互机诊断表示装载本系统的机器作为诊断主机，去诊断另一台故障机器。

接口采集故障机还能运行 Target Agent，Controller 通过 HTTP API 采集证据并自动诊断。
离线证据故障机不能联网但还能导出 runtime_info.json，可把证据包复制到诊断主机。
无法交互故障机断电、无法启动或死机，只能根据型号、症状和现场观察生成指导。
远程描述客户只能描述肉眼可见现象时，系统输出初步判断、补采问题和现场操作建议。

软硬件边界如何理解

软硬件边界是诊断归因边界，不是物理边界；它描述软件栈控制硬件、硬件状态反馈软件的交互位置。

软件侧驱动、操作系统、配置、文件系统或策略证据强，暂未发现硬件确认性异常。
硬件侧SMART、WHEA、内存测试、设备缺失或主动测试失败等硬件证据强。
软硬件边界驱动/固件/总线/控制器/接口证据与硬件路径证据同时存在，需要先做边界区分测试。
混合不确定只有症状描述、证据不足或多方向证据接近，不能直接归因或建议换件。

在被诊断机器启动 Target Agent

适用于被诊断机器还能进入系统、网络可达、允许临时运行 Python 的场景。

Windows / Linux 
python target_agent.py --host 0.0.0.0 --port 8790 --token lab-token
实验室无 Token 模式 
python target_agent.py --host 0.0.0.0 --port 8790 --allow-unsafe-no-token
  • 推荐在隔离局域网使用 Token；不要在公网暴露 Target Agent。
  • Windows 防火墙需要放行端口 8790，Linux 需要允许对应入站端口。
  • 读取部分事件日志、dump、SMART 或硬件传感器可能需要管理员权限。

互机诊断页怎么用

接口采集

  1. 在被诊断机器启动 Target Agent。
  2. 在互机诊断页填写 Target Agent 地址和 Token。
  3. 点击“测试连接/查询能力”，确认可采集证据层。
  4. 填写型号、系统、故障时间、症状和客户描述。
  5. 点击“远程采集并诊断”，系统自动采集证据并给出诊断。

离线或不可交互

  1. 如果目标机还能运行采集脚本但网络不可达，导出 runtime_info.json 后粘贴到文本框。
  2. 如果目标机已经断电、无法启动或无法运行程序，切换到“无法交互/现场指导”。
  3. 记录电源灯、风扇、蜂鸣码、屏幕文字、外接屏结果、已知正常适配器测试和照片视频。
  4. 系统只输出现场指导和补采建议，不把现场描述直接当成最终硬件结论。

典型故障怎么采证

采证目标是把用户描述转成可推理证据，而不是直接给出换件结论。

蓝屏/死机记录 stop code、minidump、WHEA、Kernel-Power、近期驱动/系统更新和崩溃时间窗口事件。
黑屏/无显示记录外接屏测试、BIOS 是否可见、背光、显示驱动日志、EDID 和面板状态。
无法充电记录电池健康、适配器功率、ACPI/UCSI 事件、充放电状态和已知正常适配器交叉测试。
无法联网记录网卡状态、驱动版本、IP/DNS/网关、ping 结果、热点对比和蓝牙共存状态。

证据层覆盖范围

inventory厂家、型号、序列号、OS、BIOS、设备管理器/PnP、PCI/USB/块设备。
logsWindows Event Log、Reliability、journalctl、dmesg、故障时间窗口事件。
metricsSMART/NVMe、电池、电源、内存、温度、网络、存储延迟。
active_tests网关 ping、外接屏、适配器交叉测试、存储短测、内存测试等状态。
crash_dumpBugCheck、minidump/MEMORY.DMP 元数据、WHEA 和 Kernel-Power 关联事件。
repair_result维修动作、是否解决、最终根因标签；用于后续论文评估。

页面功能总览

诊断功能

  • 自机检测：扫描本机、采集运行证据、异常检测、故障分类、决策和维护策略。
  • 互机诊断：Target Agent 接口采集、runtime_info 导入、现场不可交互指导。
  • 保底采集：按候选故障对象查看最低证据包和缺失项。
  • 证据明细：浏览统一 runtime_info 字段和原始指标。

研究管理功能

  • 服务性模型：查看硬件边界、软件/环境根因和可更换性标签。
  • 设备接入：选择设备类型、厂家型号并生成诊断画像。
  • 设置：配置自动刷新、采集路径、历史快照和后台采集。
  • 数据列表：检索、筛选、排序、分页和批量管理诊断案例。

常见问题

页面和服务

  • 只看到 JSON：说明打开的是 /api/health，请打开 http://localhost:8780/。
  • Target Agent 连接失败：检查目标机 IP、端口、Token、防火墙和是否在同一网络。
  • 采集不完整：部分日志、dump、SMART 或电池报告需要管理员权限。

诊断结论

  • mixed_or_uncertain 表示证据不足，不代表没有故障。
  • hardware_software_boundary 表示需要先做边界区分测试，不应直接换件。
  • 现场描述只能用于初诊和指导，论文评估仍需要维修结果和最终根因标签。

设备接入

声明设备类型和机型后，系统优先匹配知识库；未覆盖时创建自定义画像。
